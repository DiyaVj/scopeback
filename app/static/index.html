      Privacy, without the hand-waving.

      When ScopeBack uses the default http://127.0.0.1:11434 endpoint, document text is sent to Ollama running on this computer for inference. ScopeBack itself does not save uploads or add a database.

      If you change OLLAMA_BASE_URL to a remote server, your prompts and document contents will be sent there. Don't use confidential material unless you control and trust that endpoint.

      Source content may appear in your browser while the page is open. The current MVP doesn't implement account access, encryption at rest, or multi-user isolation because it doesn't persist uploaded files.
